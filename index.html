Ko-fi Discord Notification

Forward Ko-fi webhook donations to Discord instantly with a serverless Netlify Function

What is this?

A lightweight Netlify Function that instantly forwards Ko-fi webhook events to your Discord server. When someone supports you on Ko-fi, they'll get their own dedicated Discord notification with a beautiful embed showing donation amount, tier, and any custom message.

Features

  • Instant Discord notifications for every Ko-fi donation
  • Runs completely serverless on Netlify (free tier available)
  • Beautiful, customizable Discord embeds
  • Optional GitHub Gist integration to archive all supporters
  • No database required
  • Deploy in seconds with one click

Get Started in 3 Steps

Step 1: Deploy to Netlify

Deploy Now

Step 2: Set Your Tokens

During deployment, add these environment variables:

WEBHOOK_URL=https://discordapp.com/api/webhooks/...
KOFI_TOKEN=your-ko-fi-token

Step 3: Configure Ko-fi Webhook

Go to Ko-fi webhook settings and add this URL:

https://<your-site>.netlify.app/.netlify/functions/kofi

Then click the test button to verify everything works!

Environment Variables

WEBHOOK_URL=Your Discord webhook URL
KOFI_TOKEN=Your Ko-fi verification token
KOFI_USERNAME=Your Ko-fi username (optional)
GIST_URL=GitHub Gist URL (optional)
GIST_TOKEN=GitHub token for Gist updates (optional)

💡 Tip: Leave GIST_URL and GIST_TOKEN empty if you only want Discord notifications.
