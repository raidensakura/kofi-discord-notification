☕ Ko-fi Discord Notification

Serverless webhook forwarder for Ko-fi donations to Discord

What is this?

A simple Netlify Function that forwards Ko-fi webhook events to your Discord server. Receive instant notifications when someone supports you on Ko-fi, automatically delivered to a Discord channel with beautiful embed messages.

Features

  • Instant Discord notifications for Ko-fi donations
  • Runs serverless on Netlify Functions (free tier available)
  • Beautiful Discord embeds with donation details
  • Optional GitHub Gist integration to archive supporters
  • No database required
  • Easy one-click deployment

Quick Start

1. Get your tokens

  • Discord Webhook URL (from server settings)
  • Ko-fi Token (from Ko-fi webhook settings)

2. Deploy to Netlify

Deploy to Netlify

3. Configure webhook

Add your Netlify Function endpoint to Ko-fi's webhook settings:

https://<your-site>.netlify.app/.netlify/functions/kofi

4. Test it

Use Ko-fi's test webhook button to verify the integration works.

Environment Variables

WEBHOOK_URL=https://discordapp.com/api/webhooks/...
KOFI_TOKEN=your-ko-fi-token
KOFI_USERNAME=your-ko-fi-username (optional)
GIST_URL=https://gist.github.com/... (optional)
GIST_TOKEN=your-github-token (optional)
